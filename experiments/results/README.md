# 📈 Báo Cáo Kết Quả Thực Nghiệm (Results)

**Mục đích:** Lưu trữ các chỉ số đo lường (Metrics), biểu đồ, và kết quả dự đoán từ các mô hình.

## 📄 Các file quan trọng:
- `gemma_v2_results.json`: Chỉ số F1-score của mô hình Gemma-4.
- `phobert_v2_results.json`: Chỉ số F1-score của mô hình PhoBERT-v2.
- `xlmr_v1_results.json`: Chỉ số F1-score của mô hình XLM-R-v1.
- `benchmark_xai_cache.json`: Cache các lý luận (reasoning) phục vụ cho Dashboard.

## 📊 Công cụ hỗ trợ:
Dữ liệu ở đây sẽ được dùng bởi `app/streamlit_demo.py` để hiển thị Dashboard trực quan.
