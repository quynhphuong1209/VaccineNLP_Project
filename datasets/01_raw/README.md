# 🔴 BRONZE LAYER - Dữ liệu Thô (Raw)

**Mục đích:** Lưu trữ dữ liệu gốc trực tiếp từ các nguồn (Apify, APIs, Scrapers).

## 📄 Nội dung:
- `target_urls_fb.txt`: Danh sách các URL Facebook cần thu thập.
- Các file JSON thô được tải về từ `scripts/apify_multi_router.py`.

## ⚠️ Lưu ý:
Dữ liệu ở đây chưa qua xử lý, có thể chứa lỗi encoding, HTML tags, hoặc dữ liệu rác. Không sử dụng trực tiếp để huấn luyện mô hình.
